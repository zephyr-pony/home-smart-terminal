# 表格整理

用户传了一张表（Excel / CSV），要「整理一下」「把日期统一」「合并重复的」「出个能打的版本」时用。

## 步骤

1. 先 `file_read` 看结构：有几个 sheet、列名、大概多少行、有没有合并单元格或空列。
   只看前几十行就够，别把整张表读进上下文。
2. 想清楚要改什么，**只改用户说过的部分**：
   - 空行/空列：默认删，但删完要说删了几行
   - 日期：统一成 `YYYY-MM-DD`，原来的写法在汇报里提一句
   - 金额/数量：保两位小数，别四舍五入成整数
   - 重复行：按用户给的判重列（没说就按整行完全相同）
   - 表头：合并单元格拆开后，第一行必须是列名
3. 用 `run_python` 跑（pandas；写 Excel 用 openpyxl）。输入在环境变量 `XIAOMA_IN`，
   结果写到 `XIAOMA_OUT` 指向的**文件路径**。`scripts/inspect.py` 是个可直接改的模板。
4. 回报改了什么：行数从多少到多少、动了哪几列、发现了什么问题（缺列、类型混、日期不合法）。
   一句话说清，不要逐行列出来。

## 边界

- 不补数据。缺的列就说不缺不了的，不要用平均值、上一行的值去填。
- 不删用户没让删的行。判重规则不确定就先问一句「按哪一列算重复」。
- 公式、图片、条件格式这类东西 pandas 会丢；用户在意就先说明「导出后公式会变成数值」。
- 表很大（几万行以上）只处理用户要的那几列，别整表流式读进来再拼。
